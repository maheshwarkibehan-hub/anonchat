FAQ

Frequently Asked Questions

Got questions about how AnonChat works? We believe in 100% transparency.

Is AnonChat really 100% anonymous?

Yes. We have zero user registration, no cookies, no tracking pixels, and no database for user accounts. When you join, you are given a temporary random socket token that expires the moment your tab closes.

Where are my messages stored?

AnonChat requires zero accounts or registration. Audio notes and photos are ephemeral in RAM and never written to disk. Text message transcripts, turn order, and timestamps are recorded in private server session files for community safety, platform quality, and AI training, without attaching personal user profiles.

Can I send images or screenshots?

Yes! You can drag & drop photos or click the paperclip icon. You can also turn on "View Once" mode so the image self-destructs after 8 seconds of viewing.

What is the "Joby Sir" Discipline Alert?

A fun campus meme feature! If severe profanity or harassment is detected, Joby Sir's emergency siren goes off and the chat can be immediately terminated.

How does skipping work?

Just click the "Next" button in the chat header or press the 'Esc' key on your keyboard. We have a 3-second accidental skip protection bar so you don't lose a great chat by mistake.

Do I need to install an app?

Not at all! AnonChat is a Progressive Web Application that works smoothly across any mobile phone, tablet, laptop, or desktop browser.

Session & Storage Details

How conversation data is actually handled

● What Is Saved

Text messages, send timestamps, sender turn order, reply quote references, and message type metadata (such as text, voice_note, or image) are recorded into private session archive files on the server for community safety, quality review, and dataset training.

● What Is NOT Saved

Raw voice note audio recordings and attached image bytes are ephemeral in active server RAM only. Neither audio bytes nor photo bytes are written to or retained in the session archive.

● Disappearing Features Clarified

  • 5s Self-Destruct Messages: The message bubble visually dissolves and is removed from both active screens after 5 seconds, but its text is included in the session archive transcript.
  • View-Once Photos: The recipient can view the photo for up to 8 seconds before it is removed from the view. The image bytes are not archived on the server. (Note: view-once cannot prevent screenshots or cameras outside the app).

● Registration & Identity

AnonChat is 100% registration-free. We do not require emails, passwords, names, or user profiles. Server transcripts are securely restricted to the server administrator and are never exposed across anonymous browser sessions.
